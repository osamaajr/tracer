# Tracer performance refactor — 6 October 2026

## Baseline and scope

Baseline: clean commit `782287b` (`Autoplay demo when it scrolls into view`). No applicable `AGENTS.md` was found in the repository or ancestor directories. Existing source, scripts, manifest, tests, fixtures, documentation and public asset references were inspected. No dependency versions, lockfile, persistent data, storage keys, permissions, messages, API contracts or deployment settings were changed. No deployment, release or push was performed.

Initial checks encountered offloaded dependency file read timeouts and Vitest worker startup failures. `npm ci --ignore-scripts --no-audit --no-fund` restored the exact lockfile dependency versions. Baseline measurements and comparisons use the subsequent working toolchain. The baseline serial test run completed with 159 passing tests and six failing popup assertions. Baseline type checking and production builds passed; lint reported 16 errors.

## Implemented changes and measurements

1. **Bound currency formatter reuse.** `formatMoney` lazily retains up to 32 formatters, keyed by the exact currency input and existing integer/fractional formatting option. FIFO eviction bounds memory. It caches formatter objects, not prices/results; every value is still formatted on demand. Invalid currencies continue to throw. No persistent cache or migration.
2. **Compact extension packaging.** Added esbuild `--minify-whitespace` only. Identifiers, global entry names, exported interfaces, diagnostic strings, target, scheduling and runtime logic are retained. Generated bundles are less convenient to read line-by-line; readable source and existing startup traces remain.
3. **Skip identical sky style writes.** Keep the same RAF, scroll formula, 24 px cap, reduced-motion behavior and cleanup; write the CSS property only when its numeric value changes. Initial and reverse-scroll updates still occur.
4. **Remove an unused asset lookup and its imports.** `_retailerAsset` had no callers and was not exported. Its eager asset imports made Vite emit four unused PNGs despite the helper being tree-shaken. Removing it prevents those production files from being emitted.
5. **Safe lint cleanup.** Remove an unused API type import, unused initialization, and redundant regex escapes without altering their matching sets. Remove the unused legacy public scroll script.
6. **Regression and measurement tools.** Added three currency tests covering all ICU-supported currencies, fractional/integer values, casing, exceptional inputs, invalid-currency errors, reuse and eviction. Added `scripts/measure-performance.mjs` to reproduce formatter timing and bundle byte/parse measurements.

The reproducible Node parsing proxy measured popup compilation at 3.54 → 3.06 ms per unique source string and background at 0.88 → 0.72 ms. Saved-product capture showed no reliable parse improvement (1.83 → 1.84 ms in one run); do not interpret small differences as a regression or claim universal parse gains. These measurements include Node/V8 compilation allocation and are not live Chrome popup startup measurements.

Built direct price checks with immediate controlled responses measured 0.166 → 0.121 ms median for a small sale fixture. Network time was excluded by the stub. The extraction algorithm was not optimized; these tiny timings are context, not evidence of faster retailer requests.

Instrumented production pages recorded resource entries, paint timing, long tasks, heap snapshots, video state and sky writes. Warm-cache and video range-request behavior made page-load/heap differences unsuitable for a defensible speed or memory claim. Both sampled initial loads had zero recorded long tasks. The existing 4.63 MB video remains the dominant media transfer; inline product images remain part of the landing JS.

## Remaining bottlenecks, retained candidates and gaps

- Live Chrome window control was unavailable because the Mac was locked. Actual extension cold-start/usable timing, Chrome popup close/reopen, browser restart, MV3 suspension/restart, real notifications and retailer-tab injection remain **unverified in live Chrome**. Alarm/monitor/repository unit tests, source inspection, fixture replay and production syntax checks cover only their controlled portions.
- Real retailer network latency, rate limits, dynamic pages and bot defenses remain outside deterministic timing comparisons. No freshness, frequency, concurrency, fallback or retry changes were made to improve apparent speed.
- `WatchlistRepository.connect` rewrites the saved list even with no matches: controlled baseline of 100 unmatched calls produced 100 reads/writes and 21,400 serialized bytes. Retained because skipping writes or batching could change error/durability/order behavior. It continues to have a single serialized writer.
- The content-script mutation observer still monitors unrelated pages to support later SPA navigation. Removing/restricting it could lose supported purchase detection; retained.
- Date formatter reuse, popup fade updates and image preload retention are additional candidates, but were not given speculative optimizations without sufficient measurements and equivalence evidence.
- The unreachable legacy `_Dashboard` and related CSS are retained: they contain unique prototype work and overlap current site styles. No wholesale CSS purge or prototype deletion.
- `public/assets`, extension-state/order development fixtures, image PNG originals referenced by `docs/saved-item-image-prompts.md`, font licensing/source files and the unpacked extension `dist` are intentional or ambiguous; retained. No cleanup of `.tracer-data`, settings, secrets, configuration or user purchases.
- The new formatter cache trades bounded object retention (maximum 32) for lower repeated CPU allocation. It disappears with its JS context and does not change storage freshness.

## Existing behavior issues left outside this task

- Scroll reveal still selects `.landing-b-video-placeholder`, while the current video uses `.landing-b-video`. Consequently the video does not participate in that reveal sequence. Correcting the selector would visibly change animation and was left out.
- The video visibility handler can resume a manually paused video when the document becomes visible again. Changing that policy is observable and was left out.
- The six popup discrepancies above remain for a separate investigation.
