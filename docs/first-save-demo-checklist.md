# First-save demo checklist

Use this checklist to record a short walkthrough for desktop Chrome shoppers who have a product in mind. The viewer should be able to say where the item goes after saving it and what a price-drop alert means.

## Record the save

1. Open a public product page on a shop where the current Chrome Web Store build can save the item. Use a page and browser profile that expose no personal information.
2. Open Tracer, select **Save to Tracer**, then open **View saved items**. Hold on the saved card long enough to read the product name and price, if captured.
3. Close the original product tab. From **Your items → Saved**, select **Open item** and verify that it returns to the same product.
4. If the clip also shows an alert, use a real captured alert or the visual on the [Tracer homepage](https://tracercart.com/) labelled **Price-drop alert example**. Cut to that shot separately so the edit doesn't suggest an alert fires immediately when you save.

## Share and learn

- Suggested caption: “I built Tracer for products you might buy later. Try saving one product you already have in mind.” Link to the [Chrome Web Store listing](https://chromewebstore.google.com/detail/tracer/dhefgfndmihnonnclclmmjmgnhidgokm). Mention that shop support varies.
- Ask one follow-up: “After your first save, was it clear where to find the item again?”
- Record confirmed first saves and specific points of confusion. Track installs, clicks, and views separately when the data is available.
