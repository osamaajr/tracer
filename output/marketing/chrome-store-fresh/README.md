# New Tracer campaign concepts

Four different concepts: warm editorial morning desk; sculptural bell and price arrow; curated product flat lay; parcel after purchase. Each final PNG is opaque RGB, 1280×800.

The illustrations were created with the built-in image generation tool. Final text uses the exact landing-page AnthropicSerif-Roman-Web.woff2 font at weight 400, normal kerning and -0.02em letter spacing, with font synthesis disabled. The exact outlined Tracer landing-page logo is inserted directly from its original asset. These are promotional artwork; supplement with actual extension screenshots.

render.mjs and the self-contained HTML files provide editable native text. backgrounds/ retains every generated illustration. manifest.json records font and layout checks.
