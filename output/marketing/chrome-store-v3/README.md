# Exact-font Tracer promotional images

All five images are 1280×800 opaque RGB PNGs. Headlines, supporting text and alert text use the landing page's actual AnthropicSerif-Roman-Web.woff2 file at weight 400, with normal kerning and -0.02em letter spacing. Font synthesis is disabled. The original outlined Tracer logo is placed directly from the landing-page asset.

These are editable native layouts using previously generated illustrations. No new image generation was needed for this typography revision. The approved wording and generated artwork were retained. The original generation prompt set is in ../chrome-store-v2/README.md. Each HTML file embeds the exact font and artwork. render.mjs recreates the exports, and manifest.json records the computed typography and layout checks for every image.

Final exports: 01-save-it.png, 02-price-drops.png, 03-after-checkout.png, 04-your-maybes.png, 05-one-place.png. All five are included in tracer-exact-font-images.zip.
