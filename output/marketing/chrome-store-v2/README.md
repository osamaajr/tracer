# Tracer Chrome Web Store artwork

Five opaque landscape PNG exports, each exactly 1280×800 pixels.

The built-in image generation tool created the illustrations. The final artwork uses the actual landing-page font (AnthropicSerif-Roman-Web.woff2, weight 400, letter spacing -0.02em) and the original outlined logo asset (tracer-wordmark-outline-transparent.webp). Font, branding and copy are rendered directly in Chrome instead of being generated within the illustrations.

These are promotional illustrations; pair your selected artwork with actual extension screenshots.

Files: 01-save-it.png, 02-price-drops.png, 03-after-checkout.png, 04-your-maybes.png, 05-one-place.png. HTML designs are self-contained editable exports. Original generated backgrounds are retained in backgrounds/. render.mjs reproduces the exports using bundled Playwright and isolated headless Chrome. manifest.json records layout checks.

Size guidance: https://developer.chrome.com/docs/webstore/images
